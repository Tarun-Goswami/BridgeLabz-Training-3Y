Q6. Responsive CSS Cheat Sheet

Topics appear in a multi-column grid on larger screens and stack into rows below 700px.

Filters

Change how images look.

filter: grayscale(100%);

Media Queries

Apply styles at chosen screen widths.

@media (max-width: 700px) { ... }

Responsive Design

Layouts adapt to the user's screen.

width: 100%; max-width: 1100px;

Typography

Use fluid font sizing with limits.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Build rows and columns for content.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Flexbox

Align items in a row or column.

display: flex; gap: 1rem;

Q9. Responsive Design Principles Summary

Fluid Layouts

Use flexible units instead of fixed page widths.

width: 90%; max-width: 1200px;

Flexible Media

Make images fit their containers without overflow.

img { max-width: 100%; height: auto; }

Breakpoints

Change the layout when the viewport becomes smaller.

@media (max-width: 600px) { ... }
